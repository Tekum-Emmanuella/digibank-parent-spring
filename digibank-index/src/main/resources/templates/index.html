🏦 Digi Bank

Cloud Architecture Lab 3: Monolithic Architecture with Spring Boot

📋 Project Overview

This is a multi-module Maven project demonstrating a monolithic architecture for a digital banking system. The application is built with Spring Boot 3.2.5, Java 17, and uses PostgreSQL for persistence. It is designed for deployment on WildFly application server using JNDI DataSource configuration.

Spring Boot 3.2.5 Java 17 PostgreSQL JPA/Hibernate Thymeleaf WildFly JUnit 5 Cucumber

📦 Module Structure

🔧 digibank-shared

Shared components including BaseEntity and common DTOs used across all modules.

👤 digibank-customer

Customer management module with CRUD operations for customer entities.

💳 digibank-account

Account management module handling bank accounts and balances.

💸 digibank-transaction

Transaction processing module for recording financial transactions.

✅ digibank-compliance

Compliance validation module with BDD tests using Cucumber.

🏠 digibank-index

Web module providing the landing page and UI components.

🚀 digibank-app

Deployment module packaging the application as a WAR for WildFly.

🔌 REST API Endpoints

Customer API

Method Endpoint Description
GET /api/customers Get all customers
GET /api/customers/{id} Get customer by ID
POST /api/customers Create a new customer

Account API

Method Endpoint Description
GET /api/accounts Get all accounts
GET /api/accounts/{id} Get account by ID
POST /api/accounts Create a new account

Transaction API

Method Endpoint Description
GET /api/transactions Get all transactions
POST /api/transactions Create a new transaction

Compliance API

Method Endpoint Description
GET /api/compliance/validate/{amount} Validate transaction amount (max 10,000)

⚙️ Configuration

Database: PostgreSQL with JNDI DataSource (java:/jdbc/DigiBankDS)

Deployment: WildFly Application Server

Context Root: /digibank-app

JPA DDL: Auto-update mode for development
